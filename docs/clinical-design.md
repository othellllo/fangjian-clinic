# 病历书写与用药安全设计（中医 / 西医分开）

> 依据：
> - 《中医病历书写基本规范》（国中医药医政发〔2010〕29 号）——门诊初诊/复诊病历必填内容、中医诊断含病名与证候
>   [原文](https://www.szfy120.com/nurse/view/20240102Kcjx11697.html)
> - 十八反、十九畏、妊娠用药禁忌（广东省中医药局整理）
>   [原文](http://szyyj.gd.gov.cn/zyyfw/ysbj/content/post_4041482.html)
>
> 声明：规则用于提示医生，不替代医师判断；最终由医师签名负责。

## 一、中医 / 西医病历分开

### 中医门诊病历必填（初诊）

| 字段 | 说明 | 校验 |
| --- | --- | --- |
| 主诉 | 主要症状 + 持续时间 | 必填，≤50 字，建议含时长（如"2 周"） |
| 现病史 | 发病、演变、诊治经过、十问 | 必填，≥20 字 |
| 既往史 | 既往疾病、过敏史 | 必填（无则写"无"） |
| 望诊 / 闻诊 / 问诊 / 切诊 | 中医四诊 | 望、切诊必填；闻、问诊建议填 |
| 舌象 / 脉象 | | 必填 |
| 中医病名 | 如"胃痞""不寐" | 必填 |
| 证候诊断 | 如"脾胃气虚证" | 必填 |
| 治则治法 | 如"健脾益气" | 必填 |
| 方药 / 医嘱 | 处方或处理意见 | 至少一项 |

### 西医门诊病历必填

| 字段 | 说明 | 校验 |
| --- | --- | --- |
| 主诉 | 症状 + 时长 | 必填 |
| 现病史 | ≥20 字 | 必填 |
| 既往史 | | 必填 |
| 体格检查 | 生命体征 + 阳性/阴性体征 | 必填 |
| 辅助检查 | 化验/影像（无则写"无"） | 建议填 |
| 西医诊断 | 疾病名称 | 必填，建议带 ICD-10 编码 |
| 处理意见 | 用药/检查/随访 | 必填 |

### 复诊

复诊可省略既往史，但**四诊/体格检查、诊断、处理意见、医师签名**必须重写（不可直接沿用初诊）。

## 二、联想输入（不依赖外网）

分三类来源，按权重合并：

1. **标准术语库**（`medical_term` 表，随系统初始化）：症状、证型、舌象、脉象、治法、西医诊断、常用方名。
2. **本院历史病历**：从既往 `medical_record` 中抽取该字段的高频短语（医生越用越顺手）。
3. **药品字典**：药名 / 拼音码（处方开立时的联想）。

支持拼音首字母检索（如 `pqx` → 脾气虚证）。

## 三、AI 助写（离线优先，可接本地模型）

**核心原则：AI 只生成草稿，必须医生确认后才入病历；生成内容标注来源。**

三级模式（配置在「系统设置 → AI 助写」）：

| 模式 | 适用 | 行为 |
| --- | --- | --- |
| `LOCAL`（默认，离线可用） | 单机医馆 | 用结构化规则把主诉/四诊拼成规范的现病史草稿，不联网、不下发数据 |
| `OPENAI_COMPATIBLE` | 有内网模型（Ollama / vLLM / DeepSeek API） | 调用 OpenAI 兼容接口，`baseUrl` + `model` + `apiKey` 可配 |
| 关闭 | 不用 AI | 只保留联想 |

**数据安全**：患者数据不出本机是默认前提。接云端 API 时必须在界面上明确提示"病历内容将发送到配置的模型服务"，由管理员开启。

## 四、用药安全审查（处方开立时自动执行）

| 规则类型 | 级别 | 数据来源 |
| --- | --- | --- |
| 十八反 | **BLOCK** | `drug_interaction_rule`（如 附子/川乌/草乌 × 半夏/瓜蒌/贝母/白蔹/白及/天花粉） |
| 十九畏 | **BLOCK** | 如 丁香 × 郁金、人参 × 五灵脂、肉桂 × 赤石脂、硫黄 × 朴硝 |
| 妊娠禁忌（禁用） | **BLOCK**（妊娠状态已知时） | 巴豆、牵牛子、大戟、商陆、麝香、三棱、莪术、水蛭、斑蝥、马钱子、川乌、雄黄、砒石等 |
| 妊娠慎用 | WARN | 桃仁、红花、牛膝、大黄、枳实、附子、肉桂、干姜、木通、瞿麦等 |
| 毒性药品 | WARN | 附子、川乌、草乌、马钱子、细辛等，提示先煎/剂量 |
| 剂量超药典范围 | WARN | 药品字典 `dose_min` / `dose_max` |
| 特殊煎法未标注 | INFO | 自动补标注，见下节 |

> 十八反/十九畏在历代文献中并非绝对禁止（有"相反相成"用法），因此系统做**强提示 + 需填写理由才能继续**，
> 但妊娠禁用与毒性药超量按 BLOCK 处理。医师为最终责任人。

## 五、特殊煎法自动标注

药品字典维护 `special_handling`：

| 标记 | 含义 | 典型药 |
| --- | --- | --- |
| `PRE_DECOCT` | 先煎 | 附子、川乌、草乌、生石膏、龙骨、牡蛎、磁石 |
| `POST_ADD` | 后下 | 薄荷、砂仁、钩藤、大黄（泻下）、青蒿 |
| `WRAP_DECOCT` | 包煎 | 旋覆花、车前子、蒲黄、滑石、辛夷 |
| `SEPARATE_DECOCT` | 另煎 | 人参、西洋参、鹿茸 |
| `MELT` | 烊化 | 阿胶、鹿角胶、龟甲胶、饴糖 |
| `TAKE_WITH` | 冲服 | 三七粉、琥珀粉、川贝粉 |

开方时系统自动把煎法写入该味药的用法（如"先煎 30 分钟"），处方笺打印时逐味显示，
不需要医生手写；医生可覆盖。

## 六、质控（自动审查病历）

保存病历时执行，返回 `BLOCK / WARN / INFO` 三级：

- BLOCK：必填项缺失、诊断与证型缺失、主诉无时长、现病史过短 → 不允许保存
- WARN：四诊不全、辨证与治则不对应、复诊未更新四诊 → 提醒可保存
- INFO：建议补充项

## 七、当前实现边界

1. 术语库与规则库是**初始集**（覆盖常用药与常见证型），需要按医馆实际用药逐步扩充。
2. 剂量范围按《中国药典》常用量整理，未覆盖全部品种；超范围仅提示，不阻断。
3. 中西药相互作用规则目前只做提示级，未做完整数据库。
4. AI 生成内容不做自动入库，必须人工确认；接入云端模型时需管理员显式开启。
